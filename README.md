# KAZE GARAGE · Diseño retro JDM (Figma + web)

Diseño en Figma y página web de estilo póster retro japonés sobre el Toyota Sprinter Trueno AE86.

- **Autor:** Arana jimenez julian
- **Fecha:** 23/11/2026
- **Figma:** https://www.figma.com/design/Djo5ipeAxwoaKVsqy6z0uN

## Estructura
```
jdm-retro-figma-web/
├── figma/        archivo .fig exportado desde Figma
├── imagenes/     imágenes usadas en el diseño y en la web
├── web/          index.html, css/estilo.css, js/app.js
├── REQUISITOS.md
└── README.md
```

## Cómo ver la web
Abre `web/index.html` en el navegador (necesita internet para cargar las fuentes de Google Fonts).

## Tecnologías
HTML, CSS y JavaScript. Fuentes: Titan One, Archivo Black, Libre Baskerville y Noto Sans JP.
